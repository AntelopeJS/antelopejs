## Getting support

Ask usage and design questions on Discord, and report reproducible defects as GitHub issues. Check [Troubleshooting](/docs/guides/troubleshooting) first, then share the smallest example that shows the problem. Remove secrets, tokens, connection credentials and personal data from code and logs.

## Where to get help

### Discord

Ask questions in the #support forum of the AntelopeJS [Discord server](https://discord.gg/g4pFt6eXqu). Use it to:

- Ask technical questions, with code examples
- Suggest new features
- Share what you have built
- Talk with the developers and other AntelopeJS users

To ask a question:

1. Join the [Discord server](https://discord.gg/g4pFt6eXqu).
2. Search #support for an earlier post that answers your question.
3. If no post answers it, open a new post in #support.

::card{icon="i-ph-discord-logo" title="Discord"}
Use it for questions, for feature ideas, for help when you are stuck, and to talk with the community.
::

### GitHub issues

Report a defect or propose a feature in the [AntelopeJS issues](https://github.com/AntelopeJS/antelopejs/issues). The repository has two issue forms:

1. Go to the [issues page](https://github.com/AntelopeJS/antelopejs/issues).
2. Search for an issue that already covers your problem or idea.
3. Click **New issue** and choose **Bug report** or **Feature request**.

::card{icon="i-simple-icons-github" title="GitHub issues"}
Use it for reproducible bugs and for feature ideas that need code examples.
::

### Other places

- Follow [AntelopeJS on Twitter](https://twitter.com/antelopejs) for news and updates.

## How to ask good questions

The tips below help others answer your question on the first read.

### 1. Give the full picture

Explain more than what is broken. Include:

- What you are trying to build
- How you are trying to do it
- What you have already tried
- The relevant code

### 2. Do some research first

Before you ask:

- Read the docs
- Search #support on Discord and the existing issues
- Debug the problem yourself
- Look at the examples

### 3. Share a small example

When you show code:

- Keep it short, with only the relevant parts
- Put it in code blocks
- Paste the exact error messages as text
- Give your versions of Node.js, AntelopeJS and the operating system

### 4. Be clear about the problem

Compare these two questions.

Unclear: "It's not working!"

Clear: "When I run `ajs project dev`, I get this error: `Error: Cannot find module 'example'`"

## Common issues

::card{icon="i-ph-wrench" title="Quick fixes"}
These checks solve problems that many people run into.
::

### Module loading problems

If your modules do not load:

- Check your `antelope.config.ts` file
- Check that you added a module for every interface your modules import
- Check version compatibility
- Look for wrong paths

### Interface issues

If interfaces do not work:

- Check the contract package and its declared provider in `antelope.config.ts`
- Check that you implemented every required function
- Check your TypeScript types
- Check that you connected the implementation with `ImplementInterface`

## Help improve AntelopeJS

### Report bugs

If you found a bug:

1. Check whether someone already reported it.
2. Write a small test case that shows the problem.
3. Follow the [bug reporting guide](/docs/community/how-to-report-bugs).

### Improve the docs

If something in the docs is confusing or missing:

- For small fixes, [edit the page on GitHub](https://github.com/AntelopeJS/antelopejs/tree/main/docs).
- For bigger changes, [open an issue](https://github.com/AntelopeJS/antelopejs/issues/new/choose) that explains what to improve.
