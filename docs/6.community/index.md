Choose the page that matches your task. When you ask for technical help, include your versions, a minimal example, and the exact error. Remove credentials and personal data from anything you share.

::card-group
::card{icon="i-ph-question" title="Getting help" to="/docs/community/getting-help"}
Find the support channels and the context to include with your question.
::

::card{icon="i-ph-bug" title="How to report bugs" to="/docs/community/how-to-report-bugs"}
Give a minimal reproduction, the expected behavior, the actual behavior, and your environment.
::

::card{icon="i-ph-git-pull-request" title="Contribution" to="/docs/community/contribution"}
Choose a contribution and follow the issue, branch, and pull request workflow.
::

::card{icon="i-ph-code-block" title="Framework" to="/docs/community/framework"}
Set up the core repository, follow its design principles, and submit changes to the core.
::
::
