## Prerequisites

AntelopeJS requires **Node.js 20.19 or later**. Use a supported Node.js LTS release. Git is also required when the CLI downloads templates or modules from Git repositories.

```bash
node --version
git --version
```

## Run the CLI without installing it

Nothing needs to be installed to start. `npx` downloads the CLI and runs it, so you can create a project with one command:

```bash
npx @antelopejs/core project init my-project --template blank-typescript --pm pnpm --no-git-init
```

Every `ajs` command takes the same form after `npx @antelopejs/core`. A project created from a template has `@antelopejs/core` as a development dependency, so inside it `pnpm exec ajs` runs the CLI too.

## Install the CLI globally (optional)

Install the `ajs` command globally when you want to type it directly, using your preferred package manager:

:::code-group

```bash [npm]
npm install -g @antelopejs/core
```

```bash [yarn]
yarn global add @antelopejs/core
```

```bash [pnpm]
pnpm add -g @antelopejs/core
```

:::

After installation, the `ajs` command is available globally in your terminal.

## Verify Installation

Confirm that the CLI installed correctly by checking its version:

```bash
ajs --version
```

The command prints the installed core version. Run `ajs project init --help` to confirm that the executable exposes the project commands.

| Symptom | Check |
| --- | --- |
| `ajs: command not found` | Add your package manager's global binary directory to `PATH`, then open a new terminal. |
| Unsupported Node.js version | Upgrade Node.js and reinstall the CLI with that Node.js installation. |
| Template download fails | Check Git installation, network access, and the repository URL in the error. |

## Choose how to run AntelopeJS

- **New application:** continue with [Quick Start](/docs/get-started/quick-start). The CLI owns startup and shutdown.
- **Existing Node.js application:** follow [Embed AntelopeJS](/docs/guides/embedded-runtime). Install the core locally; your host owns startup and shutdown.

::tip
The `ajs` command is the single entry point for all Antelopejs operations — creating projects, managing modules, running builds, and more. Reference pages write commands as `ajs ...`. Without a global install, run `npx @antelopejs/core ...` instead, or `pnpm exec ajs ...` inside a project.
::
