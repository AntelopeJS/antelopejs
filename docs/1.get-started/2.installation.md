## Prerequisites

You need Node.js and, when the CLI downloads templates or modules from Git repositories, Git. The Node.js versions AntelopeJS supports are the `engines` field of `@antelopejs/core`'s `package.json`. Run `npm view @antelopejs/core engines` to read them, and use a supported Node.js LTS release.

```bash
node --version
git --version
```

## Run the CLI without installing it

Nothing needs to be installed to start. `npx` downloads the CLI and runs it, so you can create a project with one command:

```bash
npx @antelopejs/core project init my-project --template blank-typescript --pm pnpm --no-git-init
```

Every `ajs` command takes the same form after `npx @antelopejs/core`. A project created from a template lists `@antelopejs/core` as a dependency, so inside it npx runs that installed copy.

## Install the CLI globally (optional)

Install the AntelopeJS CLI globally with your package manager to type `ajs` directly:

:::code-group

```bash [npm]
npm install -g @antelopejs/core
```

```bash [yarn]
yarn global add @antelopejs/core
```

```bash [pnpm]
pnpm add -g @antelopejs/core
```

:::

The package installs the `ajs` command on your `PATH`.

## Verify the installation

Print the CLI version:

```bash
ajs --version
```

The command prints the installed core version. Run `ajs project init --help` to confirm that the executable has the project commands.

| Symptom | Check |
| --- | --- |
| `ajs: command not found` | Add your package manager's global binary directory to `PATH`, then open a new terminal. |
| Unsupported Node.js version | Upgrade Node.js and reinstall the CLI with that Node.js installation. |
| Template download fails | Check the Git installation, network access, and the repository URL in the error. |
| PowerShell says `ajs.ps1` cannot be loaded because running scripts is disabled | The execution policy blocks npm's PowerShell shim. Run `ajs.cmd` instead, or allow local scripts with `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned`. |

## Choose how to run AntelopeJS

- For a new application, continue with the [quick start](/docs/get-started/quick-start). The CLI owns startup and shutdown.
- For an existing Node.js application, follow [Embed AntelopeJS](/docs/guides/embedded-runtime). Install the core locally. Your host application owns startup and shutdown.

::tip
`ajs` creates projects, manages their modules, and builds and runs them. Run `ajs --help` to list its commands. Reference pages write commands as `ajs ...`. Without a global install, run `npx @antelopejs/core ...` instead. Inside a project that lists `@antelopejs/core` as a dependency, npx runs that installed copy.
::
