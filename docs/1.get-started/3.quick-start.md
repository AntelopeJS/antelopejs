## Your First Project

Create a project, run one module, and observe a reload. You need the [CLI, Node.js and Git](/docs/get-started/installation), plus pnpm for the commands below. This first application prints a message; it does not open an HTTP port.

::steps{level="4"}

#### Create a new project

Scaffold a blank TypeScript module with explicit choices:

```bash
ajs project init my-project --template "Blank Typescript" --pm pnpm --no-git-init
cd my-project
```

The CLI installs the template dependencies and registers the local module in `antelope.config.ts`. The project directory contains both the application configuration and its first module. Omit the flags to choose a template and package manager interactively.

#### Give the module observable behavior

Replace the blank module's entry point with this lifecycle example:

```typescript [src/index.ts]
export function construct(): void {
  console.log("Hello from my first AntelopeJS module");
}

export function start(): void {
  console.log("Module started");
}

export function destroy(): void {
  console.log("Module resources released");
}
```

`construct()` prepares the module. `start()` begins work after construction succeeds. `destroy()` releases resources during shutdown or reload; this example has no external resources to close.

#### Run the project

Start the project in development mode:

```bash
ajs project dev
```

Look for `Hello from my first AntelopeJS module`, followed by `Module started`, among the CLI output. These messages verify that the core loaded the entry point and called its lifecycle functions. Press Ctrl+C to stop it; cleanup prints `Module resources released`.

::note
`ajs project run` is an alias for `ajs project dev`. Both commands start the project in development mode.
::

#### Enable watch mode

For automatic reloading when source files change, add the `--watch` flag:

```bash
ajs project dev --watch
```

Change the greeting in `src/index.ts` and save. The generated local source configuration runs its build command, then the core destroys and replaces the module. Look for the cleanup message and the new greeting without restarting the CLI.

If your own local source configuration has no build command, watch mode does not invent one. Set `installCommand` and `reloadCommand` as described in [Creating a Module](/docs/module-development/creating-a-module#adding-the-module-to-a-project).

::

## What Happens at Startup

When you run `ajs project dev`, the following sequence takes place:

1. The core loads and resolves module configurations from `antelope.config.ts`
2. The core downloads and caches required modules
3. The core validates the interface dependency graph (ensures all required interfaces have providers)
4. Providers publish any [config variables](/docs/concepts/configuration#module-config-variables)
5. Modules execute `construct()` — internal state is initialized and interface implementations are registered
6. Modules execute `start()` — active work begins; an HTTP provider, if configured, can serve requests
