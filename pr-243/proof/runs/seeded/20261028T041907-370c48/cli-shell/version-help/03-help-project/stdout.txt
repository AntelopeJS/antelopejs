Usage: ajs project [options] [command]

Create, run and build AntelopeJS projects, and manage their modules and logging
settings.

Options:
  -h, --help                Show help for a command

Global Options:
  -v, --version             Print the version
  --verbose [=channels]     Print TRACE logs and full error details, optionally
                            for some log channels only (comma-separated)
                            (preset: "*", env: ANTELOPEJS_VERBOSE)
  -q, --quiet               Print only results, warnings and errors: no
                            progress, information or summaries (env:
                            ANTELOPEJS_QUIET)
  --no-color                Disable colors (also NO_COLOR=1)

Commands:
  init [options] <project>  Create a project
  modules                   Add, remove, list and update modules
  logging                   Show or change logging settings
  dev [options]             Run the project in development mode
  build [options]           Build the project for production
  start [options]           Start the project from its build
  run [options]             Same as project dev
  help [command]            Show help for a command
